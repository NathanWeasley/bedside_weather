# ESP8266 天气桥接器

本工程负责连接 Wi-Fi、通过 NTP 校时、获取心知天气的 3 天逐日预报，并通过 115200-8-N-1 串口向 STM32 发送二进制帧。逐小时预报代码仍然保留，但默认关闭。

## 配置与编译

1. 将 `secrets.example.h` 复制为 `secrets.h`，填写 Wi-Fi 和心知天气 API Key。`secrets.h` 已被 Git 忽略。
2. 在 `settings.h` 中设置地点、时区和刷新周期。默认地点为西安，时区为中国标准时间。
3. 使用 Arduino IDE 打开 `ESP8266_Poll.ino`，选择实际 ESP8266 板型后编译烧录。依赖 ESP8266 Arduino Core 和 ArduinoJson。

`settings.h` 中的 `ENABLE_HOURLY_FORECAST` 默认为 `0`，此时不会请求逐小时接口，也不会执行 08:00–18:00 天气变化提取。以后获得“24 小时逐小时天气预报”权限后可将其设为 `1`；逐小时接口只能返回当前时刻之后的数据，若设备在 08:00 以后才联网，天气响应的 `WEATHER_PARTIAL_DAY` 位会置 1。

## 串口协议

帧格式为：

`AA 55 | 地址(1) | 载荷长度小端(2) | 载荷(N) | 累加校验(1)`

校验值为地址、长度高字节、长度低字节以及全部载荷字节的 8 位累加和。所有多字节整数均按小端发送，所有载荷结构按 1 字节对齐。

MCU 请求载荷仅有一个字节：`1` 查询网络状态，`2` 查询时间，`3` 查询天气。响应地址如下：

| 地址 | 响应 | 载荷长度 |
| --- | --- | ---: |
| 10 | 网络状态 | 1 |
| 11 | 本地日期时间 | 9 |
| 12 | 天气汇总 | 81 |

天气汇总包含 3 天的最高/最低温、日间/夜间天气代码，以及当天 08:00–18:00 中“首个可用时点 + 天气代码变化时点”。结构的权威定义见 `protocol.hpp`；STM32 侧镜像定义位于 `App/v1/weather_protocol.h`。

## 运行策略

- 上电联网后立即拉取并主动发送一次天气与时间。
- 每次发送天气时，00:00（含）至 21:00（不含）把当天预报放入 `daily[0]`，21:00 起把次日预报放入 `daily[0]`；发出的 `daily_count` 为 1。
- 天气默认每 30 分钟刷新；失败后每 5 分钟重试，并在仍有旧数据时携带 `WEATHER_STALE` 标志返回缓存。
- 时间由 NTP 同步，每小时主动发送一次，也可由 MCU 随时查询。
- MCU 协议使用 `Serial`；可选调试日志使用 TX-only 的 `Serial1/GPIO2`，默认关闭，避免破坏二进制帧。
